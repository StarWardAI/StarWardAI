## <img src="https://raw.githubusercontent.com/StarWardAI/StarWardAI/main/assets/icons/shield.svg" width="25" height="25" alt="" /> Built around real execution

FluxOS focuses on making agent execution controllable, traceable, and recoverable.

| | Foundation | What it means |
| :---: | --- | --- |
| <img src="https://raw.githubusercontent.com/StarWardAI/StarWardAI/main/assets/icons/shield.svg" width="24" height="24" alt="" /> | **Controlled tool use** | Tool contracts, access checks, and approval policies define how actions run. |
| <img src="https://raw.githubusercontent.com/StarWardAI/StarWardAI/main/assets/icons/receipt.svg" width="24" height="24" alt="" /> | **Traceable execution** | Tool results, process exits, and task acceptance are represented separately. |
| <img src="https://raw.githubusercontent.com/StarWardAI/StarWardAI/main/assets/icons/history.svg" width="24" height="24" alt="" /> | **Recoverable state** | Persisted events, execution receipts, and checkpoints retain task history. |
| <img src="https://raw.githubusercontent.com/StarWardAI/StarWardAI/main/assets/icons/extensions.svg" width="24" height="24" alt="" /> | **Room to extend** | MCP, Skills, plugins, and connectors provide integration points. |

**TypeScript · Node.js · Electron · npm workspaces · GitHub Actions**

The FluxOS core has **10 independently built packages**, with CI on **Linux, macOS, and Windows**. Electron belongs to the desktop product; browser, computer, and terminal adapters are supplied by applications.

<details>
<summary>📦 Explore the 10 core packages</summary>

| Layer | Packages |
| --- | --- |
| Shared foundations | `contracts` · `platform` |
| Models, tools & integrations | `models` · `tools` · `extensions` |
| Agent execution | `agent-runtime` |
| State & lifecycle | `conversations` · `profiles` · `automations` |
| Presentation | `presentation` |

Package ownership and dependencies are documented in the [FluxOS architecture](https://github.com/StarWardAI/FluxOs/blob/main/docs/architecture/packages.md).

</details>
