## What we're building

StarWard connects agent infrastructure with applications for work and personal life.

| Project | Focus | Status |
| --- | --- | --- |
| **[FluxOS](https://github.com/MengShengbo/FluxOs)** | An open-source agent runtime and reusable core infrastructure. | Open source · MIT |
| **FluxAgent** | A desktop agent for practical work and multi-step tasks, built on FluxOS. | In development · Private source |
| **Eonarc** | A personal AI agent focused on long-term context, memory, and ongoing collaboration. | Early-stage development |

### FluxOS — The open foundation

FluxOS provides reusable foundations for agent execution, model integration, tools, conversations, and extensions. Its core runs independently of the desktop product; applications supply their own browser, computer, and terminal adapters.

### FluxAgent — An agent for work

FluxAgent brings the shared infrastructure into a desktop workspace, with a focus on practical work and multi-step task execution. The desktop product is developed separately from the open-source core.

### Eonarc — A personal agent over time

Eonarc is our personal AI agent in development. Its direction centers on understanding personal context, retaining useful history, and supporting ongoing collaboration.
