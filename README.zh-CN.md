## <img src="https://raw.githubusercontent.com/StarWardAI/StarWardAI/main/assets/icons/shield.svg" width="25" height="25" alt="" /> 围绕真实执行构建

FluxOS 关注 Agent 执行过程的可控、可追溯与可恢复。

| | 基础能力 | 含义 |
| :---: | --- | --- |
| <img src="https://raw.githubusercontent.com/StarWardAI/StarWardAI/main/assets/icons/shield.svg" width="24" height="24" alt="" /> | **可控的工具调用** | 通过工具契约、访问检查与审批策略约束动作如何执行。 |
| <img src="https://raw.githubusercontent.com/StarWardAI/StarWardAI/main/assets/icons/receipt.svg" width="24" height="24" alt="" /> | **可追溯的执行事实** | 分别记录工具返回、进程退出与任务验收。 |
| <img src="https://raw.githubusercontent.com/StarWardAI/StarWardAI/main/assets/icons/history.svg" width="24" height="24" alt="" /> | **可恢复的任务状态** | 通过持久化事件、执行回执与检查点保留任务历史。 |

**TypeScript · Node.js · Electron · npm workspaces · GitHub Actions**

FluxOS 内核包含 **10 个独立构建的包**，在 **Linux、macOS 和 Windows** 上持续集成。Electron 属于桌面产品；浏览器、电脑与终端适配器由应用提供。

<details>
<summary>📦 查看 10 个核心包</summary>

| 层次 | 包 |
| --- | --- |
| 共享基础 | `contracts` · `platform` |
| 模型、工具与集成 | `models` · `tools` · `extensions` |
| Agent 执行 | `agent-runtime` |
| 状态与生命周期 | `conversations` · `profiles` · `automations` |
| 呈现 | `presentation` |

包职责与依赖关系详见 [FluxOS 架构文档](https://github.com/StarWardAI/FluxOs/blob/main/docs/architecture/packages.md)。

</details>
