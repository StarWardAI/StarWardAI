## 我们在构建什么

StarWard 将 Agent 基础设施与面向工作、个人生活的应用连接起来。

| 项目 | 定位 | 当前状态 |
| --- | --- | --- |
| **[FluxOS](https://github.com/MengShengbo/FluxOs)** | 开源 Agent 运行内核与可复用的核心基础设施。 | 已开源 · MIT |
| **FluxAgent** | 基于 FluxOS 构建的桌面工作 Agent，面向真实工作与多步骤任务。 | 开发中 · 源码私有 |
| **Eonarc** | 面向长期个人上下文、记忆与持续协作的个人 AI Agent。 | 早期开发 |

### FluxOS — 开源基础

FluxOS 为 Agent 执行、模型接入、工具、会话与扩展提供可复用的底层能力。核心可以独立于桌面产品运行；浏览器、电脑与终端适配器由应用集成方提供。

### FluxAgent — 面向工作的 Agent

FluxAgent 将共享基础设施组装为桌面工作空间，聚焦真实工作与多步骤任务执行。桌面产品与开源内核分开开发。

### Eonarc — 面向长期协作的个人 Agent

Eonarc 是我们正在开发的个人 AI Agent，方向是理解个人背景、保留有用的历史，并支持持续协作。
